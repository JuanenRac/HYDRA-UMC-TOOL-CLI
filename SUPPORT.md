## 🐛 Bug Reports
If you found a real error in a CLI command or gRPC client, please open a **GitHub Issue** in this repository. 
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?
- We do not provide support for non-official CLI wrappers or third-party terminal emulators with compatibility issues.
- Please do not use Issues for "How to" questions.
